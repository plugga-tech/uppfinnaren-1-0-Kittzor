# Qvänum mat och malt

A web application developed with ASP.NET core MVC to showcase the inventors creations in a digital gallery. The project is designed to be extended in the future.

## Technologies
Programming language: C#
Framework: ASP.NET Core MVC
IDE: Visual Studio
Version Controll: Git

## Prerequisites
To run this project, you will need:
.NET SDK 6.0 or later
Visual studio 2022 or later
Git, For cloning and managing the source code

## Installation and running

Step 1: Clone the project
Open a terminal and run the following command to clone the project to your computer:
```bash
git clone https://github.com/your-username/inventor-gallery.git

Step 2: Navigate to the project directory
cd inventor-gallery

Step 3: Build the application
dotnet build

Step4: Run the application
dotnet run

Step 5: Open in the browser
http://localhost:5000
